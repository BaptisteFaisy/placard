# Direction artistique du Manoir

- **Ton** : manoir gothique dessiné, contemplatif et mélancolique plutôt qu'horrifique. Aucune image de sang, aucune agression visuelle.
- **Palette** :
  - Nuit (fond général) : `#14101F`
  - Mur de pierre : `#2A2140`
  - Os / Parchemin : `#EDE6D6`
  - Bougie / Lanterne : `#F2A541`
  - Alerte / Rouge critique : `#E4572E`
  - Poison / Données personnelles : `#8BD450`
  - Sceau de cire : `#B23A48`
  - Ruban d'exclusion : `#7C6DB8`
- **Mouvements & Animations** :
  - Tout mouvement est < 400 ms.
  - Respect strict de `prefers-reduced-motion: reduce` (désactive toutes les transitions).
- **Accessibilité** :
  - Les fiches descriptives et le registre sont rendus sur fond uni à fort contraste (ratio >= 4.5:1).
  - L'information n'est JAMAIS portée par la seule couleur (toujours doublée d'un texte et d'un pictogramme).
  - Navigation intégrale au clavier (`Tab`, flèches, `Enter`, `Escape`).
