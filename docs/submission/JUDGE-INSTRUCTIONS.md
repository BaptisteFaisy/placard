# Judge instructions — Placard (Skeletons in the Closet)

Text to paste into the Devpost "testing instructions" field.

---

## Zero-install path (recommended, ~2 minutes)

1. Open **https://baptistefaisy.github.io/placard/** — no account, no install, works in a private window.
2. You land on the **haunted manor** of a synthetic repository: 12 findings spread over **5 floors** (one floor per year of history, 2022 → 2026).
3. Click any **door** (a door = a commit hiding at least one finding). The finding sheet shows: family, masked preview, danger score **and every term that produced it**, locations, and the secret's lifetime.
4. Select a skeleton to light up the **bony footprints**: the path that one secret walked through the manor, across floors, from the commit that introduced it to the commit that removed it.
5. Switch to the **Registry Table View** tab: the same findings as an accessible, sortable, filterable table (WCAG AA, keyboard only).
6. Open **Costume Legend** (top right): every decorative element mapped to the data it encodes.
7. Drag and drop your own `report.json` onto the page (top-right button) — it is read **in the browser**, never uploaded.

Everything you see was produced by the real engine: the embedded report is generated by `placard scan` on a generated repository, not hand-written.

## Local path (~5 minutes)

Requires Node 20+ and Git.

```bash
git clone https://github.com/BaptisteFaisy/placard.git
cd placard
pnpm install

# Generate a synthetic haunted repository and scan it
pnpm exec tsx packages/cli/src/main.ts demo --target /tmp/placard-demo

# Serve the manor for that report (http://127.0.0.1:<port>)
pnpm exec tsx packages/cli/src/main.ts serve /tmp/placard-demo/.placard/report.json

# Or scan a real repository of yours — nothing leaves your machine
pnpm exec tsx packages/cli/src/main.ts scan /path/to/your/repo
```

## What to look for

| Thing to check | Where |
|---|---|
| A secret removed from the code is still found in history | Any finding with a "removed" commit and no "in HEAD" badge |
| The score explains itself | Finding sheet → list of applied terms (`+15 still in HEAD`, `−30 test path`, …) |
| The ritual enforces the right order | Ritual panel: **Purge is locked** until Rotation is checked |
| No secret is ever printed | Reports, logs and stdout contain only masked previews and HMAC fingerprints |
| The tool scans itself | `pnpm exec tsx packages/cli/src/main.ts scan . --fail-on-open` exits `0` on this repository |
| The whole acceptance recipe | `bash scripts/recette-c17.sh` |

## Honest limits

- Placard **never uses a secret it finds**: no key is ever validated against a provider.
- Placard **never rewrites your repository**: it writes a `git filter-repo` script for you to review and run on a mirror clone.
- Detection covers 9 families; it is not a general security audit.
