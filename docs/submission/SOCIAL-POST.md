## Main post (short)

#KiroweenHackathon26 I built **Placard** — a secret scanner for Git history
disguised as a haunted manor. One floor per year, one door per guilty commit,
spiderwebs for age, and bony footprints tracing how long a leaked key actually
lived.

What I like most in Kiro: **steering files that the agent cannot argue with.**
Mine says "no decorative element — every ghost must encode a fact". The custom
reviewer agent rejected an animated bat I was perfectly happy with, because the
bat encoded nothing. That is a stricter design review than most humans give me.

It changed how I work: I write the invariants first (specs + steering + hooks),
then let the agents build inside them. 11 packages, 543 tests, 24 PRs — the last
12 merged by the queue with no click from me, including one whose conflict was
resolved by an AI agent that was summoned by a CI gate.

Demo, no install: https://baptistefaisy.github.io/placard/
Code (MIT): https://github.com/BaptisteFaisy/placard
